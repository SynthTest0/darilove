# DARI LOVE — состояние проекта

Лендинг сексолога, личный бренд, Москва. Собран, отревьюирован, задокументирован. Этот файл — точка входа для новой сессии.

## Где что лежит

| Путь | Что это |
|---|---|
| `index.html` | вся разметка страницы, контракт направления — HTML-комментарий первым потомком `<body>` |
| `css/base.css` | токены, бархатное поле, зерно, общий материал, пилюля, оправа фотографии |
| `css/site.css` | композиция страницы |
| `js/content.js` | **единственный файл для правки контента**: цены, места, тексты карточек, FAQ, ссылки |
| `js/site.js` | гейт, шапка, пин-карусель, модалка, инерция скролла, состояния скролла |
| `assets/img/` | шесть обработанных кадров (WebP, 576 КБ) |
| `PRODUCT.md` | продуктовая правда: аудитория, ограничения, что нельзя выдумывать |
| `DESIGN.md` + `.impeccable/design.json` | дизайн-система, выведенная из собранного кода |

Стек: статика без фреймворка и без сборки. Git инициализирован, восемь коммитов, ветка `main`.

Локальный просмотр: `python3 -m http.server 4321 --directory /Users/synthb0y/Claude/darilove`. Конфигурация для панели браузера уже лежит в `/Users/synthb0y/Claude/.claude/launch.json` под именем `darilove`.

## Что за страница

Направление «Переплёт»: страница как переплетённая вручную книга. Корешок слева — единственная вертикальная ось, ляссе отмечает прочитанное, золочёный обрез разгорается при прокрутке, колофон вместо прайс-таблицы, четыре тома вместо карточек-плашек.

Порядок секций: гейт 18+ → липкая шапка → сплит-геро → манифест → пин-карусель четырёх томов → живой формат → приватная консультация → обо мне → отзывы (удаляются, пока список пуст) → FAQ → блок заявки → подвал. Липкая нижняя полоса появляется после карусели.

Продажа не на сайте: все кнопки ведут в Telegram, ссылки уже размечены `?start=<slug>` под будущего бота.

## Решения, которые нельзя молча переигрывать

Всё это согласовано с клиентом в длинном опросе; менять только по его прямой просьбе.

- **Ни одного чистого чёрного на поверхностях страницы.** Самый тёмный токен — `--ink #241017`, поле упирается в `--wine-deep #2C1015`, все тени вишнёвые, не нейтральные. Исключение: сами фотографии, где остался их студийный почти чёрный фон — клиент попросил снять тонирование, компромисс принят осознанно.
- **Фотографии идут в собственном цвете.** Дуотон снят. Оправа даёт фон, обрезку и радиус, но не фильтр и не режим наложения.
- **Палитра снята пипеткой** с фотографий бордового латексного платья, не подобрана абстрактно.
- **Шрифты Cormorant Garamond + Golos Text.** Кириллица проверена по отдаваемому CSS: у Cormorant она есть в прямом и курсиве, у Golos только в прямом — поэтому каждый курсив на странице набран Cormorant.
- **Старостильных цифр не будет** на этой гарнитуре: в GSUB поставляемого Cormorant только `calt, ccmp, dnom, frac, liga, lnum, locl, numr, tnum`, таблицы `onum` нет. Открытый вопрос к клиенту: оставить прописные или взять третью гарнитуру под цифры.
- **Один примитив анимации** — переменная `--fill` по прокрутке плюс `--read` для прогресса чтения. Она ведёт линейку под заголовком, маску подмены кадра, золочение обреза, ляссе и тики корешка. Новые эффекты добавляются к этому примитиву, а не рядом с ним.
- **Один рецепт материала** на все поднятые поверхности: светлая грань сверху, внутреннее затемнение книзу, мягкая внешняя тень. Пилюля — форма нажимаемого, прямоугольник со скруглением — форма карточки.
- **Никаких надзаголовков-плашек** над заголовками: убраны финиш-ревью, возвращать нельзя.
- **Порядок в шапке**: Обо мне · Оглавление · Живой формат · Поблагодарить · Написать в Telegram.
- **Порядок первого экрана на телефоне**: заголовок → абзац → темы → кнопки → фотография → прайс. Для этого геро разделён на `.hero__lead` и `.hero__price` как отдельные элементы сетки.
- Ховеры только при точном указателе, `prefers-reduced-motion` сохраняет прозрачность и цвет и убирает перемещение, пин отключается на тач-устройствах и при ширине ≤1020px, инерция скролла и пружина на краях работают только при точном указателе и не мешают пину.
- Заголовок вкладки и OG нейтральны: пересланную ссылку видят посторонние.

## Ловушки, на которые уже потрачено время

- **Локальный headless Chrome не снимает кадр после программной прокрутки** — возвращает ровное поле, воспроизводимо, даже на странице без JS. Снимать так: поднять нужную секцию в начало документа, спрятав предыдущие через инъекцию CSS, и снимать без скролла. Гейт при этом обходится записью `localStorage.setItem("darilove:age","ok")` до `content.js`. Инъекции в рабочий файл не коммитить.
- **Панель браузера часто скрыта**, и тогда `requestAnimationFrame` заморожен: состояния, которые считаются по прокрутке, не пересчитываются, а снимки выходят чёрными. Проверять DOM через `javascript_tool`, а не глазами по скриншоту.
- Пин-карусель пересчитывает режим на `resize`; шаг сдвига берётся из реальной раскладки, а не из фиксированного зазора.
- Ширина корешка живёт в токене `--spine`; от неё зависят отступ страницы и левый край нижней полосы.
- Правки через `str.replace` в Python молча не срабатывают, если строка в файле уже изменилась. Проверять результат, а не намерение.

## Статус качества

Финиш-ревью `impeccable` пройдено, вердикт `ship` по восьми материальным правкам и двум регрессиям. Механический детектор `detect.mjs` по `index.html`, `css/base.css`, `css/site.css`, `js/site.js` возвращает пусто, при этом сам сообщает о деградации: не установлены `htmlparser2`, `css-select`, `css-tree`, `domutils`, поэтому проверка идёт регулярками и является недооценкой.

Незакрытым по решению клиента остаётся один пункт потолка — старостильные цифры (см. выше).
